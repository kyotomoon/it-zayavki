# ИС «IT-Заявки» — клиентская часть сайта учёта заявок в IT-отдел

Курсовой проект, группа ИСП-0039А. Сайт на HTML, CSS и JavaScript без фреймворков.
Все данные сайт получает с сервера **json-server** через REST API (`/api/...`).
localStorage, sessionStorage и cookie не используются.

## Как запустить

**Быстрый способ (Windows):** дважды щёлкнуть `start.bat` в папке проекта. Он сам установит json-server, запустит его и откроет сайт в браузере. Окно не закрывать, пока работаете с сайтом.

> Открывать `index.html` двойным щелчком без запущенного сервера нельзя: данных не будет, сайт покажет «Сервер не запущен».

**Через терминал:**

Нужен установленный [Node.js](https://nodejs.org) (версия 18 или новее).

1. Открыть папку `it-zayavki` в VS Code (или другой IDE).
2. В терминале выполнить один раз:
   ```
   npm install
   ```
3. Запустить сервер:
   ```
   npm start
   ```
4. Открыть в браузере **http://127.0.0.1:3000** — это главная страница сайта.

json-server одновременно отдаёт страницы сайта из папки `public` и API по адресу
`http://127.0.0.1:3000/api/...` (правило `/api/*` → `/$1` из `routes.json`).

Если открыть сайт через Live Server (другой порт), он тоже работает — но json-server
при этом должен быть запущен командой `npm start`.

## Авторизация и регистрация (по подзадачам)

- Проверка полей формы входа и регистрации (пустые поля, формат почты и телефона, длина и совпадение паролей).
- Сообщения пользователю: «Пользователь с такой почтой не зарегистрирован», «Неверный пароль»,
  «Пользователь уже авторизован», «Добро пожаловать…», «Регистрация прошла успешно», «Вы вышли из системы».
- После входа — переход в личный кабинет своей роли (сотрудник, специалист, администратор).
- Войти могут только пользователи из базы (`GET /api/users?email=...`).
- Повторно войти нельзя, пока пользователь уже авторизован: при входе в базе у пользователя
  записывается поле `lastSeen` и обновляется каждые 30 секунд; при выходе или закрытии вкладки
  оно очищается. Если `lastSeen` свежее 90 секунд, повторный вход запрещается (даже с другого компьютера).
- Выход из личного кабинета — кнопка «Выйти» с подтверждением.
- Регистрация заносит нового пользователя в базу (`POST /api/users`).

## Что умеет сайт

- **Главная**: логотип, шапка с меню (на телефоне — кнопка-бургер), цифры и последние заявки из базы.
- **Вход и регистрация**: проверка почты и пароля запросом `GET /api/users?email=&password=`,
  регистрация нового сотрудника `POST /api/users`, проверка полей форм.
- **Сотрудник**: свои заявки с поиском и фильтрами, создание заявки, карточка с историей статусов и комментариями.
- **Специалист**: назначенные заявки, смена статуса, общая очередь заявок, комментарии.
- **Администратор**: статистика, все заявки и назначение исполнителя, пользователи (добавление, смена роли,
  удаление), справочники (категории, отделы, приоритеты).
- **Уведомления** (колокольчик): заявки, требующие внимания для текущей роли.
- **Тёмная тема**: переключатель «солнце/луна»; по умолчанию берётся настройка системы.
- **Адаптивная версия**: ПК, планшет и телефон (от 360 px).

Вошедший пользователь хранится только в памяти страницы, поэтому после перезагрузки
нужно войти снова — так сделано, потому что localStorage использовать нельзя.

## Выложить на Netlify (чтобы открыть сайт с любого компьютера)

1. Зайти на https://app.netlify.com/drop.
2. Перетащить туда **папку `public`** (не всю папку проекта!) или архив `netlify-site.zip`.
3. Netlify выдаст ссылку вида `https://….netlify.app`.

На Netlify нет json-server, поэтому сайт сам включает демо-режим: данные загружаются
запросом fetch из файла `data/db.json`, а новые заявки, комментарии и пользователи
сохраняются только до перезагрузки страницы. Если позже выложить json-server
(например, на Render), его адрес вписывается в `public/js/config.js`, и демо-режим отключится.

## Выложить на Render (общие заявки для всех, бесплатно)

На Render работает настоящий json-server: заявка, поданная с одного компьютера, видна на всех остальных.

1. Создать на GitHub новый репозиторий `it-zayavki` (Public) и через «Add file → Upload files»
   загрузить все файлы проекта, **кроме папки node_modules**.
2. Зайти на https://render.com, нажать «Get Started» и войти через GitHub.
3. «New → Web Service» → выбрать репозиторий `it-zayavki`.
4. Заполнить: Build Command — `npm install`, Start Command — `npm run start:render`,
   Instance Type — **Free**. Нажать «Deploy Web Service».
5. Через 2–3 минуты появится ссылка вида `https://it-zayavki.onrender.com` — это и сайт, и API.

Особенности бесплатного тарифа: после 15 минут без посещений сервер засыпает,
первое открытие после этого занимает около минуты; при перезапуске база возвращается к исходному db.json.
